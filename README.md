# LinuxSystemResourceMonitor
Linux System Resource Monitor (TUI) - Microproject to determine C/Linux ability


Description: Interacts directly with the Linux kernel via the virtual /proc filesystem and POSIX APIs, rendering an interactive, real-time dashboard without relying on heavy external runtime dependencies. --- Project Idea pulled from Gemini

Functions: CPU Metrics Engine, Memory & Swap Monitor, Network & Disk I/O Tracker, Process Table & Task Manager, Terminal User Interface
